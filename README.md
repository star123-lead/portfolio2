## 🚀 How to Host This on GitHub Pages (Under 2 Minutes)

1. **Create Repository:** Create a new repository on GitHub (e.g. named `portfolio`).
2. **Push Code:** Upload the files inside this directory directly to the root of your `main` branch.
3. **Enable Hosting:**
   - Go to **Settings** -> **Pages**.
   - Under *Build and deployment*, set *Source* to **Deploy from a branch**.
   - Select **`main`** and **`/ (root)`**, then click **Save**.
4. **Go Live:** Your site will be active in seconds at `https://<your-username>.github.io/portfolio/`.
