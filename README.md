## 🔧 Running Locally

This is a static HTML/CSS/JS site — no build step required.

```bash
# Clone the repository
git clone https://github.com/your-username/starinulagam.git

# Navigate into the folder
cd starinulagam

# Open in browser
open index.html
# or serve with any static server:
npx serve .
```
