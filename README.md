## 📌 Overview

This is the **official personal portfolio website** of **Thangamani Palanivel** (known as **Star**), a BCA Final Year student at PGP College of Arts and Science, Namakkal, Tamil Nadu.

## ✨ Features

- 🌗 **Dark / Light Theme Toggle** — remembers user preference via `localStorage`
- 📜 **Scroll Reveal Animations** — smooth `IntersectionObserver` based reveal
- 🧠 **Skill Modal System** — click any skill chip to view detailed description and associated projects
- 📊 **Animated Count-Up Stats** — numbers animate when the About section enters view
- 📬 **Interactive Contact Hub** — LinkedIn, Email, Phone, GitHub, Instagram tabs with copy-to-clipboard
- 🖼️ **Profile Image Toggle** — click photo to switch between two profile pictures
- 🗂️ **Project Detail Modal** — PROTECT ME card opens a full feature breakdown popup
- 📱 **Fully Responsive** — mobile-first layout with adaptive grid and hidden nav on small screens
- ♿ **Accessible** — ARIA labels, keyboard navigation, semantic HTML5 structure

## 📁 Project Structure

```
portfolio/
│
├── index.html          # Main HTML file (single-page)
├── style.css           # All CSS styles (or embedded in index.html)
├── script.js           # All JS logic (or embedded in index.html)
│
├── favicon.png         # Brand logo / favicon
├── background.png      # Circuit board background texture
├── profile.jpg         # Primary profile photo
├── profile2.jpg        # Secondary profile photo (toggle)
├── preview.png         # OG image for social sharing (1200×630)
│
├── Resume2.pdf         # Downloadable CV
├── site.webmanifest    # PWA manifest
├── robots.txt          # Search crawler rules
├── sitemap.xml         # Sitemap for Google indexing
└── vercel.json         # Vercel headers + redirects config
```

## 🏃 Run Locally

No build tools needed — it's plain HTML/CSS/JS.

```bash

git clone https://github.com/star123-lead/portfolio.git

# Open in browser
cd portfolio
open index.html
# or just double-click index.html
```

```bash
# Right-click index.html → Open with Live Server
```
