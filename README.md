## ⚙️ &nbsp;Run Locally

> **No build step required** — this is a pure static site.

```bash
# 1. Clone the repository
git clone https://github.com/your-username/starinulagam.git

# 2. Navigate into the project
cd starinulagam

# 3. Open in browser directly
open index.html

# — OR — serve with a local static server
npx serve .
```
